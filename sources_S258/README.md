# ARM22 Task 7.1.4 - Intersessional task group S-258-201 edtion 1 proposal

Netherlands (Rijkswaterstaat) proposed the introduction of S-158:201 Validation checks for S-201. The WG agreed on the introduction of validation checks using IALA’s S-258 rather than the IHO’s S-158 numbering. Draft S-258:S-201 validation rules will be uploaded to the S-201 GitHub and the Netherlands (Rijkswaterstaat) will run intersessional meetings to progress this task. 

Action Item ARM22-27	Committee participants are invited to join the intersessional task group (Virtual meetings) working on Task 7.1.4 S‑258/S‑201 Validation and to express their interest to Peter Schwarzberg (peter.schwarzberg@rws.nl) by 1 June 2026, noting the dates and times of the intersessional meetings will be announced in due course and published on the Committee Dashboard.	21
Action Item ARM22-28	The Intersessional Group Leader is requested to provide input on the intersessional work on Task 7.1.4 S‑258/S‑201 Validation to ARM23.
